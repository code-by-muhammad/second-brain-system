The v0.1.6 audit fixes passed independent Codex and Claude reviews, four-platform CI and Windows deployment. Subsequent real owner edits and a new upstream import exercised two additional cases. This follow-up preserves that release and its evidence; it does not rewrite the earlier review results.

Current status, 2026-10-16: **HOLD — v0.1.7 is a candidate, not an approved installation.** R126 and R127 source-screen repairs and R128 common mapping-construction bounds have sealed scoped Windows/native Linux evidence. R129's additional common integer-construction repair also has sealed scoped Windows/native Linux evidence. None of these scoped passes establishes final combined-source acceptance. The completed combined source has not yet passed its own frozen full suites, exact original-contract replay, evidence binder, actual integration and fresh Codex/Claude reviews. Native Mac, hosted CI, tag, deployment and physical-client acceptance remain pending and unwaived. Production remains v0.1.6 and PRIMARY remains `0ed` unchanged. Use v0.1.7 setup/update examples only after the shared system status explicitly approves that release.
