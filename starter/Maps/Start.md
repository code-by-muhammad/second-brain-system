# Your Second Brain

Capture something in `00-Inbox`, then move it deliberately to the right home.

| Folder | Put this here |
|---|---|
| 00-Inbox | Unsorted notes; AI-Captures holds immutable saved milestones |
| 01-Projects | Active work with an outcome or deadline |
| 02-Areas | Ongoing responsibilities; AI-Memory is reserved for sourced summaries |
| 03-Resources | Reusable reference material and decision notes |
| 04-Archive | Inactive/completed material, retained as history |
| 05-Daily | Daily notes and weekly reviews |
| 06-People | Source-backed contact notes; no guessed personal facts |
| 07-Meetings | Curated meeting notes, grouped by a chosen project/client |
| Attachments | Local images/PDFs; separate reviewed publication/backup |
| Maps | Navigation and index pages |
| Templates | Eight reusable note formats |

Use Obsidian's Templates command for non-daily notes. Daily notes use the daily template automatically after local configuration. The service links saved milestones into daily notes only on a designated maintainer. It does not automatically sort your inbox or import meetings.

Do not copy another person's notes or identity to initialize your brain. Wiki pages do not exist until an explicitly authorized compiler publishes evidence-backed claims. See [[Maps/AI-Context]] for the initial workflow.
